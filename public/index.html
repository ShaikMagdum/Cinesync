Deploy CineSync to Cloud (Free)

Single Node.js process serving both static frontend and WebSocket signaling. Zero databases needed!

Option 1: Render.com (Recommended Free)
  1. Push this repository to your GitHub account.
  2. Go to dashboard.render.com > Click New + > Web Service.
  3. Select your repository.
  4. Build Command: npm install
  5. Start Command: node server.js
  6. Select Free Plan > Click Create Web Service.
Option 2: Replit (Instant 1-Click)
  1. Log into replit.com > Click Create Repl.
  2. Choose Import from GitHub or Node.js template.
  3. Set Run Command to node server.js and press Run.
Option 3: Railway.app
  1. Log into railway.app > New Project > Deploy from GitHub.
  2. Railway automatically runs node server.js and generates a public HTTPS URL.

Why CineSync is private:

1. The decryption key is generated in your browser and shared via the URL fragment (#key=...).

2. RFC 3986 specifies that fragments are never sent to the web server.

3. Messages are encrypted with AES-256-GCM before leaving your device.
